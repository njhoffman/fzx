# fzx TODO

Status: the six steps of `docs/design.md` are done, plus the git module, key help (f1), the debug view
(f2), `fzx debug attach` and the zsh widgets. Modules: `ps`, `files`, `logs`, `systemd`, `git`, `menu`.
Keep this file current: tick items off, add what you find.

Every item carries a priority in its first line, `(p1)` high, `(p2)` normal or `(p3)` low, and a
category: `[bug]` `[feature]` `[refactor]` `[docs]` `[test]` `[chore]` `[perf]`, plus this repo's own below.
`(due YYYY-MM-DD)` adds a date and an OVERDUE flag. `/todo` and `/todo-pop` (`~/.shell/scripts/todo-status`,
`todo-fzf`) sort and mark by them; `todo-status --check` lists untagged items.

Categories: module

## Roadmap

- [ ] **Piping** (p3) [feature]: when stdin is not a tty and no module is given, match each manifest's `detect`
      against the first lines and pick the module (design.md, "Piping"). PLAN.md calls it a nice-to-have.
- [x] **Key help**: `fzx::bind <key> <action> <description>` records bindings; f1 shows them in the
      preview; systemd's header is generated by `fzx::key_hints`.
- [x] **Debug preview key**: f2 shows session state, cached data, `FZF_*` variables and the raw
      focused line in the preview.
- [x] **`fzx debug attach [sid]`**: bash + curl prompt on the session's `fzf.sock` (state, raw, actions),
      plus one-shot `debug state` and `debug send`.
- [ ] **Menu ordering by use** (p2) [feature]: sort entries by `stats.tsv` (recent and frequent first), maybe a
      "recent" group on top.
- [ ] **git** (p2) [feature]: commit-to-files drill-down (ctrl-o on a commit lists its changed files with per-file diff),
      fetch, commit/amend in `execute`, blame preview, worktrees. Discard/restore stays opt-in only.
- [x] **Shell integration**: `shell/fzx.zsh` widgets on alt-f/d/g/p/m (insert paths, cd, git, pids,
      menu) and `just install` (symlink `bin/fzx` into ~/.local/bin).
- [ ] **Sessions module** (p3) [module]: a picker over `fzx debug ls` that resumes a kept or running session from
      another terminal.
- [ ] **New modules** (p2) [module]: see "Module candidates" below; pick by priority.

## Issues and limitations found

- [ ] **Undocumented fzf behaviour we depend on** (p2) [test]: `become()` inside a `--popup` runs in the original
      terminal, so every launch re-requests the popup (`fzx::_placement`). Observed on fzf 0.74 (devel);
      re-check on every fzf upgrade with the popup test in design.md's popout notes.
- [x] **No linting** (p1) [chore]: `just lint` (shellcheck, `.shellcheckrc`) is clean;
      `.github/workflows/ci.yml` runs lint and `bats test` on ubuntu-24.04 (verified in a local container).
- [ ] **Log rotation** (p2) [bug]: `$XDG_STATE_HOME/fzx/fzx.log` is never rotated or pruned; add it to `fzx gc`
      like the stats file.
- [ ] **Summary cache is keyed by directory only** (p2) [bug]: git summaries (ahead/behind, changes) stay stale for
      up to `FZX_SUMMARY_TTL` (5m) after a commit or stage. Key git entries on repo state (HEAD, index
      mtime) instead.
- [ ] **Menu `applicable` runs synchronously** (p2) [perf] for every entry on every open; one slow check slows the
      menu. Log per-module timing, or time-box it like summaries.
- [ ] **Untested against the real thing** (p2) [test]: docker (stubbed only), systemd start/stop/enable (stubbed
      systemctl and sudo), Zellij popups (tmux only).
- [ ] **grep mode stats noise** (p3) [bug]: every keystroke in `files:grep` records a `source reload` row;
      record live-search reloads as their own event or not at all.
- [ ] **`files` alt-up** (p3) [bug]: each parent directory becomes a new child session instead of reusing an
      existing ancestor in the tree; harmless (cleaned on exit) but deep trees and long labels.
- [ ] **`persist=none` sources have no item count** (p3) [bug] in stats (output streams straight to fzf).
- [ ] **Exit row missing** (p3) [bug] when the terminal is killed (SIGHUP); the dead tree is swept by gc but
      the run never gets an `exit` stat.
- [ ] **Stats prune** (p3) [bug] can drop rows appended while the file is being rewritten.
- [ ] **`fzx stats` needs `strftime` in awk** (p3) [bug] (gawk, or mawk 1.3.4+).
- [ ] **Bash scoping** (p3) [bug]: functions returning through a variable name use `_`-prefixed locals; a
      caller variable with the same `_` name is still shadowed. Keep caller variable names un-prefixed.
- [ ] **Slow suite** (p3) [test]: `bats test` takes ~2 minutes serially; `bats -j` needs GNU parallel (this
      machine has the moreutils `parallel`).

      no longer competes with a global load bind.
